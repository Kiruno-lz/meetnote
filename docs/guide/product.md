# 产品定位与设计

> 从 PRODUCT.md 提纯，保留产品定位、用户画像、品牌与设计原则。

## 产品定位

meetnote 是一个本地桌面工作台，把会议音频的**转录、speaker 区分与人工修正、忠实去口语化整理和 Markdown 纯文件历史库**整合成一个可追溯的本地工作流。

**核心价值主张**：隐私（数据不离本机）+ 可控性（用户决定模型和修正结果）。

**成功标准**：用户能在不依赖任何云端 API 的情况下，把一段会议录音整理成一份可直接归档的 Markdown 文件。

## 目标用户

中文会议参与者（产品经理、研发、运营、研究员）在 Mac 桌面上处理会议录音。

- **使用场景**：会后静态处理，几十分钟到几小时的会议音频
- **隐私敏感**：不希望会议内容上传到任何云端服务
- **核心任务**：导入音频 → 核对发言人 → 确认去口语化结果 → 导出 Markdown

## 品牌调性

精确、克制、可信赖。工具气质，不做表演。设计服务于工作流，不抢注意力。

### Anti-references（不想要的设计方向）

- 不要 SaaS 产品的过度圆润和渐变背景（Notion / Figma 主页风格）
- 不要 AI 产品的"未来感"霓虹视觉（Midjourney / Claude 主页）
- 不要 productivity app 的过度品牌化（Todoist 橙色大标题）
- 不要 Windows-style 密集 toolbar
- 不要 VS Code 颜色 token 的机械风格（灰色主导、毫无层级）

## 设计原则

1. **流程优先于功能展示**：每个屏幕只有一个主任务，其他元素退到背景。
2. **密度匹配内容类型**：转录文本紧凑，操作区域有足够点击目标。
3. **可逆、可追溯**：编辑操作有确认和回退路径。
4. **工具气质**：控件朴素精确，功能复杂性在交互层处理，不在视觉层展示。
5. **隐私可见**：用户能看到数据在哪里、模型在哪里，不做"黑箱"设计。

## 无障碍

- 最低 WCAG 2.1 AA 对比度
- 支持键盘操作的主流程（Tab / Enter / Escape）
- 动效保守，支持 `prefers-reduced-motion`
